# Student Registration App

A dynamic web application developed using Java, JDBC, Servlets, and JSP that allows users to manage student records efficiently.

## 🚀 Features
- Add new student details
- View all registered students
- Update student information
- Delete student records
- Form validation and error handling
- Database connectivity using JDBC

## 🛠️ Technologies Used
- Java
- JDBC
- Servlets
- JSP
- HTML
- CSS
- MySQL

## 📂 Project Structure
- Servlet classes for request handling
- JSP pages for UI
- JDBC for database connectivity
- DAO pattern for data operations

## ⚙️ How to Run
1. Install Apache Tomcat Server
2. Configure MySQL database
3. Import project into Eclipse/IDE
4. Run the project on server
5. Access in browser: http://localhost:8080/

## 💡 Key Concepts Used
- MVC Architecture
- CRUD Operations
- Database Connectivity
- Session Handling
- Request & Response Handling
